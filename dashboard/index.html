How graduation is predicted

Nothing in the snapshot says a token is coming. The model scores each protocol from the snapshot's own figures only: scale (TVL against the $50M floor), momentum (7-day TVL change), staying power (days listed with no token), and breadth (chains spanned). Those four signals feed a graduation probability; the implied value is TVL × 0.30 × (0.50 + probability), adjusted for growth, maturity and breadth. The window (3–6, 6–12, 12–18 or 18–24+ months) is a bucket of that probability, never a date. No protocol name is special-cased — the same function scores every row, and the detail view shows every input behind each number.

A protocol on this board records no token. That is not proof it has none. Implied values are this entry's own claim, never make.fun's.
